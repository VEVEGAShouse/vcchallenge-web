# vcchallenge.com

Archivo de VC Challenge (2020–2024). Es una sola página en HTML, CSS y un poco de JavaScript, publicada gratis con GitHub Pages.

- `index.html`: textos.
- `styles.css`: diseño.
- `field.js`: la animación de la portada (unos 100 puntos que se agrupan en los cinco países y se conectan) y los contadores.

Para cambiar un texto: abre `index.html` en GitHub, pulsa el lápiz, edita y pulsa **Commit changes**.
