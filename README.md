# vcchallenge.com

Archivo de VC Challenge (2020–2024), de Virginia E. Vegas. Una sola página en HTML, CSS y JavaScript, publicada gratis con GitHub Pages.

- `index.html`: textos y el formulario «Don't be shy, come say hi».
- `styles.css`: diseño (paleta original: negro, hielo y lima).
- `app.js`: animaciones (enjambre de la portada, historia de los ~100 gestores al hacer scroll) y el formulario (nota, llamada de 30 min, nota de voz).

Pendiente: poner el enlace de Calendly en `app.js` (`CALENDLY = '...'`) y activar FormSubmit con el primer mensaje que llegue a hello@vevegas.com.

Para cambiar un texto: abre `index.html` en GitHub, pulsa el lápiz, edita y pulsa **Commit changes**.
